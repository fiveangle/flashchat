# 08 — Split expert reads: original proposal and recovered early probes

Status: **PROPOSAL SUPERSEDED BY 14; earlier prototypes had negative results.**
Reconstructed on 2026-09-16; no new tests run.

## Hypothesis

Read an expert's gate/up weights first, start their GPU computation, and overlap
the remaining down-projection read with that work. The historical packed expert
was 1,769,472 bytes: a 1,179,648-byte gate/up prefix and 589,824-byte down suffix.
These sizes describe the campaign's model, not every supported model.

## Recovered chronology

1. The original [index](../README.md) lists 08 as pending. The August 24
   [analysis, section 4.3](../12-pin-default-on/campaign-analysis/ANALYSIS.md)
   says "exp/08 never built" and directs implementation to 14.
2. A separate August 17 worktree investigation nevertheless tested the same
   idea. Its notes survive at
   `/Users/speedster/dev/flashchat-work/docs/explorations/10-wonderment-round/NOTES.md`.
   That worktree's number 10 is **not** this archive's experiment 10 (prefill
   regression). Subsequent cross-checkout Git review found `a399937`, whose
   index explicitly marks 08 rejected based on these probes. The full notes
   and commit are now preserved in [25](../25-wonderment-recovered/NOTES.md).
3. That source records these decode observations:

   | Scheduling | Control tokens/s | Split tokens/s |
   |---|---:|---:|
   | All gate/up and down fragments dispatched together | 10.81 | 9.97 |
   | Prefix first, suffix alongside GPU work | 11.10 / 11.08 | 10.52 / 10.48 |

   Both schedules reportedly generated byte-identical output. The first
   schedule made suffix reads compete with the prefixes needed to start GPU
   work. Staging reduced the loss, but the investigator attributed the remaining
   cost to the additional Metal command-buffer boundary. The prototypes and
   extra buffers were removed. These are recovered historical observations,
   not a newly verified causal attribution or current regression threshold.
4. [Experiment 14](../14-expert-read-split/NOTES.md) later recorded a positive
   result and shipped in `5af6a43`. Its implementation bypasses split scheduling
   for all-pin-hit layers, and its measurements used fusion and output-weight
   residency. Do not compare absolute speeds across these sessions or claim
   that one specific change explains the reversal: no matched cross-version
   attribution was recovered.
5. [Experiment 21](../21-io-event-gating/NOTES.md) later tested GPU event gating.
   Its negative result further documents why issuing both read waves together
   can destroy the useful overlap. This does not invalidate 14's shipped path.

## Conclusion and provenance

The concept was neither universally disproven nor an untested free win. Read
14 and 21 before revisiting; preserve prefix priority and evaluate extra GPU
submission costs. The early worktree notes and session
`01a00fba-6c27-7b80-8900-ba076e1ecf71` (August 17, assistant messages at JSONL
lines 534 and 703) corroborate the discarded probes. The numerical evidence
above is copied into this archive so it does not depend on that worktree's
continued existence. The unique commit is now also archived under 25; it
contains API rows for the cache-bypass campaign, but not raw split-read runs.
